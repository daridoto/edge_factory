# Conocimiento

Lo que se va descubriendo al validar hipótesis: hallazgos, razonamientos, definiciones y preguntas abiertas. Complementa a `resultados/` (cifras fijas por experimento) y a `ESTADO.md` (qué toca ahora, se reescribe).

- **Una nota por hipótesis** (`H-NNN.md`) y **una por concepto** transversal (`conceptos/`).
- **Solo se añade.** Si algo resulta falso, se tacha y se explica debajo; no se borra.
- **Cada hallazgo lleva fecha y fuente:** campo de `resumen.json`, experimento, página del paper (`W…`, en el repo de papers) o «cálculo en conversación, no guardado».
- **Enlaces `[[...]]`** entre hipótesis, conceptos, experimentos y papers. Abriendo el repo como bóveda de Obsidian se ve el grafo.
